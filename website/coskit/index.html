03 / ONE CONTINUOUS WORKFLOW

从一句目标，到可继续编辑。

AI 与基础编辑共享工程。
保留图层，也保留作出选择的过程。

01 / REASON + REVIEW↗

会执行，也会检查。

Harness 自主观察、发现 MCP 工具、执行并验收。可请求原尺寸局部检查；发现问题时回退并调整方案。

02 / LOCAL CONTROL↗

最后一笔，仍然交给你。

选区、蒙版、图层、曲线和修复工具，加上发丝、光影、氛围笔刷。MCP 可精确设置轨迹、压力与流量。

03 / REPLAYABLE PROJECT↗

把尝试也保存下来。

CKPipe 保存图层、参数、对话和可回退版本。用可视化参数调整配方，再从指定基准生成新分支。

04 / LOOK CLOSER↗

细节，不只看缩略图。

版本同步缩放、原尺寸对比、200% 放大与差异图。浏览对比保持当前画布和工程记录不变。

05 / INSTALL + BUILD

从这里开始创作。

v1.0.0 / 第一个正式版本

Windows x64

提供安装版与便携 ZIP。便携版解压后运行 coskit.exe；基础编辑无需配置模型。

查看发行页 ↗

从源码构建

Rust 1.95+ · Node.js 20+ · Python 3
Windows 需 C++ Build Tools；打包另需 NSIS。

git clone https://github.com/DongSky/CosKit.git
cd CosKit
npm run build
