# CosKit 1.0.0-beta.8 — P1：AI 效率、细节验收与参数对比

日期：2026-10-10。延续原先确定的三个 P1，不将 P0 的剩余瓶颈混入完成范围。

## AI 调用效率

模型仍根据用户目标自行拟定步骤。新增 `batch` 决策：1–6 个相关的低风险原生操作组成事务，全部命令先检查范围与已发现参数，执行后共用一次独立视觉审核。事务中途报错、像素保护失败或视觉审核退回，恢复整个事务前的文档与图层目标；本轮运行此后只能逐步执行与审核。生成、重型滤镜及其他结构操作不允许批量绕过单独验收。

允许批量的操作为笔刷、已有图像调整、13 类本地无损调整图层创建（排除需外部查找表的 colorLookup）、图层属性/调整参数及矩形、椭圆、全选、取消选择。批量只是减少模型往返，不取消最终验收、画布/色彩/位深/ICC 和选区外像素保护。取消和总时间预算同样适用。

每个运行保留最多 64 条、合计约 64 KB 的已发现命令说明，并持续提供给决策模型。未变化文档的全图预览、文档观察和最多 16 个有界工具结果可以复用；修改或回退立即失效。缓存为本机运行内缓存，不代表供应商端 token 缓存或跨请求免费。启动时仅做无分配的文档边界校验，去掉未使用的整图编码。

审计记录包含决策、事务失败、回退、审核、观察缓存命中数和文本模型逻辑调用次数。供应商内部 HTTP 重试可能额外发生，不能将逻辑调用数当作最终账单。

## 全图与原尺寸局部验收

决策支持 `inspect`，模型可以自行指定原图坐标区域。审核器同时看到全图和围绕实际变化像素的默认裁片，并可返回 `verdict: inspect` 请求其他区域，最多追加两轮检查。每次 1–3 个区域，每边 1–640 像素；同一坐标下提供原始、上一步和候选三张裁片。请求超界、预算用尽或不能给出明确审核结论时不提交候选。

裁片直接从原生文档在对应区域合成，无缩略图放大；全图与裁片均经过显示色彩转换。审核器累计保留此前裁片和观察结论，重复区域不再编码，并明确告知剩余复查次数；审计保留各轮检查坐标和结论。原生合成与保护仍支持 8/16/32 位，发送给视觉模型的是 sRGB PNG 显示代理。局部检查是有界采样，不能保证检查了每个像素；模型供应商还可能自行缩放输入。

## 参数编辑与版本对比

版本条的「参数」打开独立配方窗口，选择基准版本与可重放记录：

- 13 类已有调整复用原生滑杆、曲线、色阶和色彩编辑器。
- 笔刷、选区和常用图层参数提供数值、布尔和颜色控件；复杂数组及特殊参数保留「高级 JSON」。蒙版绘制记录继续保留其目标和笔刷参数，不自动改变取样目标。
- 打开控件不会归一化或重写记录；只有用户修改时才更新配方。基准版本由用户明确选择，不自动重算全部历史下游步骤。
- 参数重放在隔离后台任务执行，成功后生成新分支，可一次撤销。取消、失败、并发新增对话均不能覆盖原状态。

「对比」提供同步缩放/拖动、100% 原尺寸、200% 放大镜，以及显示差异 ×4。左右使用同一原图区域，历史版本直接解码真实图层并局部合成；关闭后释放缓存。每次只保留一个历史文档、一个后台区域任务和三张不超过 1024×768 的纹理，不创建全尺寸 GPU 对比纹理。显示差异包含透明度变化，是显示代理差异，不替代高位深数据校验。

首次查看版本仍需解码该历史文档；内存预算是软限制，该比较文档与临时缓冲可能增加 RSS。低倍率全图比较仍需要更多合成工作，缩放后局部区域的缓存不会当成新区域使用。界面百分比按 UI 坐标计算，系统 DPI 缩放影响物理屏幕像素。

### 真实模型与本机时延

使用已配置的真实模型，对 5472×3648 照片工程只输入“略降曝光、略增饱和度、保留人物与细节”的目标，没有指定命令、参数、步骤或裁片坐标。最终程序中，模型先发现工具，再自行将曲线和自然饱和度调整图层组合为一个事务；审核器主动追加一轮局部检查，累计查看四个 640×640 区域后接受结果。共 2 轮决策、4 次逻辑文本调用、2 次观察缓存命中，0 次图像生成、0 次回退，49.33 秒完成并保存 CKPipe。画布仍为 5472×3648，原图层保留，结果可整体撤销。

另一次成功的单步运行耗时 187.57 秒、9 次逻辑文本调用，各步骤分别审核。两次运行由模型自行选择不同工具和复查数量，不是受控性能对照，不能据此承诺固定的速度或费用降幅。事务共享审核和缓存命中的行为均由审计记录及回归测试确认。

首次真实测试曾因审核缺少前轮裁片与观察记录而反复申请局部，耗尽预算后未提交原文档。现已修复累计证据，补充剩余轮数说明及回归测试；实际模型连续两轮追加检查也已成功通过。还补全了 batch 的顶层字段示例，避免模型将 actions 误放在 arguments 中；无效事务仍被拒绝并记录原因。
