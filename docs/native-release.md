- 完整命令注册表的异常参数测试：通过，无 panic 或超过测试阈值的挂起。
- 另执行编辑器、引擎与桌面应用测试：142 项集成测试、83 项桌面应用单元测试通过；其中重复执行的 2,051 项引擎/UI 单元测试不重复计入上面的库测试数量。集成套件默认跳过 4 项，其中异常参数检查已单独执行。

- 最终发布二进制重启后重新打开上述 AI 分层文档，三个图层及持久化对话恢复检查通过。
- WebAssembly：完整原生 UI 及依赖（含 HEIF）的 wasm32 编译检查通过。上游条件编译下的未使用常量警告仍存在。

## 发布与边界

Windows 默认构建启用 HEIF，并同时构建桌面应用与 CLI。交付包包含原生程序、CLI、原许可证和使用指南，不包含 `.env`、模型密钥、开发数据或测试图片。安装器不会自动运行或上传用户图片。

这里的「一比一」指完整保留该参考项目当前实现与交互，不代表修复其所有既有缺陷或实现它尚未完成的 Photoshop 行为。参考项目的格式/色彩/功能边界仍见 `native/docs/roadmap.md` 与 `native/docs/scorecard.md`。没有重新运行需另行下载的完整真实 PSD corpus；本轮使用现有单元/集成与合成文件往返验证。

AI 使用 sRGB 8 位代理图，原始分层文档的高位深及色彩模式不被降级。默认版不启用旧 Tauri 入口的可选外部 GPU 美颜 SDK。安装包未签名，未实际安装到系统；macOS/Linux 原生运行未在本机验证。
