# CosKit v1.0.0-beta.2：完整 PhotoCraft 集成

用户要求：PhotoCraft 已支持的编辑功能一比一保留，不再以基础修复子集作为交付范围。本方案替代 beta.1 的范围限制。

## 实现方式

`native/` 纳入参考 PhotoCraft 的完整、独立可构建源码快照（不依赖相邻目录）。保留 L0–L6 文档、像素、色彩、算法、合成、IO、插件、命令和原生 UI。所有原有命令、工具、菜单、快捷键、对话框、预设、格式和自动化接口继续使用同一实现。

CosKit 默认桌面入口改为完整原生编辑器。原 Tauri 前端作为旧版入口保留，已有会话和设置不删除。原 AI 的供应商、规划、工作流、技能、参考图及审核代码由 `coskit-ai` crate 直接共享，避免重写导致行为差异。

原生编辑器右侧增加可收起的 AI 对话区；窄窗口改用底部面板。发送时取当前文档不可变快照及选区，后台生成 sRGB 代理图交给原 AI 工作流。AI 结果经 ICC 转换回当前文档色彩空间，并以新图层加入，保留全部原图层及位深，支持原生撤销/重做。请求进行时不锁住传统编辑；文档或版本变化时拒绝自动应用，结果可单独打开。

## 对齐范围

| 能力 | 实现与 UI 来源 |
|---|---|
| 全部画笔、铅笔、混合器、图章、历史画笔、橡皮、模糊/锐化/涂抹、修复/修补/红眼/内容识别移动 | `paint`、`algo`、`engine` 与原 toolbar/flyout |
| 矩形/椭圆/套索/多边形/磁性套索/魔棒/快速/对象选区、选区修改、通道与快速蒙版 | 原 selection/channel 命令及 UI |
| 移动、裁剪、切片、自由变换、变形、透视、操控变形、液化 | 原几何命令、交互预览及参数面板 |
| 图层/组、27 种混合模式、蒙版/矢量蒙版、剪贴、调整/填充图层、图层效果、智能对象/智能滤镜 | 原完整 document 与 compose 引擎 |
| 文字、竖排、段落、字符、字体选择、文字变形 | 原 text 与 type UI |
| 钢笔、路径、直接选择、形状、路径/填充/描边 | 原 vector 与 UI |
| 调色、曲线/色阶等调整、滤镜及滤镜库、Camera Raw | 原 algo 与全部参数对话框 |
| RGB/Gray/CMYK/Lab 等模式、8/16/32 位、ICC、软打样 | 原 CMS、color、raster、GPU/CPU 合成 |
| PSD/PSB、原生分层格式、TIFF、PNG/JPEG/WebP/EXR/RAW、HEIF 等已实现格式 | 原 IO/codecs，Windows 构建启用 heif |
| 多文档、历史、动作/批处理、预设、偏好、主题、标尺/参考线、自动保存/恢复 | 原完整应用外壳及服务 |
| CLI、MCP、控制协议、插件 | 完整源码与原有注册表；桌面与 CLI 同包交付 |

以参考项目当前实际行为为标准，包含其已声明的限制。627/627 表示菜单已接入，不能将其表述为完整 Photoshop 行为一致。CosKit 不删除参考项目的功能，也不把上游尚未完成的能力说成已完成。

## 验收

1. 固定上游提交，生成源码指纹及集成改动清单，核查功能文件无遗漏。
2. 运行上游菜单 parity 门槛、引擎/算法/格式/UI 测试与新增 AI 集成回归。
3. 真实窗口验证菜单、工具、传统编辑与 AI 同文档往返、撤销、分层保存重开。
4. 真实模型仅使用合成图烟测；不打包 `.env` 或个人数据。
5. 发布完整原生版 Windows 程序、CLI、许可证、使用文档与验收记录。
