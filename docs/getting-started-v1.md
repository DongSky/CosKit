# CosKit 1.0.0 新手指南

## 安装与模型

安装 Windows x64 安装包，或解压便携 ZIP 后运行 `coskit.exe`。打开照片和使用图层、修复、笔刷等基础编辑无需 API。需要对话修图时，在右侧「AI 修图」的「选项」中填写你自己的提供商地址、密钥和模型名。自主模式的文本模型必须能理解图像；图像编辑模型负责可选的生成式处理。

教程不会展示真实密钥。模型配置保存在本机，图像请求按你选择的提供商发送；不要把 `.env` 或程序数据目录上传到代码仓库。

## 用一张照片走完流程

1. **打开**：`Ctrl+O` 选择照片；确认底部尺寸。先另存为 `.ckpipe`，保留原文件。
2. **记录基准**：底部版本条给当前阶段命名，例如「原片」。原图层保留，重要局部手工修改前再建版本。
3. **描述目标**：例如「让花间人像清新通透，保留肤质、发丝、花朵和白衣层次，不改变构图与人物身份」。无需指定命令或操作步骤。
4. **查看审核**：模型会自行设计方案、选择工具并复查效果。展开「查看修图过程与效果检查」阅读简短行动与结果记录。失败或取消不会把未审核的隔离结果提交。
5. **手工收尾**：在新图层上处理光影、发丝或特效，调低笔刷流量与图层不透明度，让改动保持克制。常用笔刷可从工具选项和笔刷面板选择。
6. **比较**：选择起始版本后点「对比」。切换适合窗口、100% 原尺寸、200% 放大，左右同步查看；差异图用于定位变化，不等同于质量评分。
7. **参数**：点版本条「参数」，明确选择基准与操作记录，调整曲线、滑杆或高级 JSON 后重放。成功后产生新分支，可整体撤销；不要把错选的基准当成最近画面。
8. **保存与导出**：保存 `.ckpipe` 留下图层、参数、对话与版本。PNG/JPEG 是合成成片，会丢失图层；PSD/PSB 用于与其他编辑器交换分层文档。

## 常见问题

- **模型看起来没有动**：先查看任务状态。网络和供应商等待可能较长，可取消；取消已经发出的远端请求不保证免除供应商计费。
- **结果没被应用**：审核未通过、预算用尽、取消或原工程并发变化都可能阻止提交。先查看错误和记录，不要反复提交相同请求。
- **AI 改了尺寸吗**：自主原生工作流会检查画布尺寸、色彩模式、位深和 ICC。生成式处理使用代理图，生成层的细节分辨率可能低于原图，但不会因此缩小原工程画布。
- **版本很多会占多少内存**：CKPipe 跨版本共享数据块，缓存和历史有软预算；解码文档与大型临时计算仍会使用额外内存。
- **Android 在哪里**：本次没有发布原生 Android 包，已列入 TODO。旧 Tauri 移动端资料不是本次正式版交付。

## 演示真实性

配套视频录制真实 CosKit 窗口，通过 MCP 驱动实际操作；等待片段在剪辑中加速并标注，旁白为本机合成语音。成片演示包括自主调整和独立图层笔刷收尾。原始照片、录屏、工程和导出保存在本地素材包，公开页面只需经过脱敏的网页衍生素材。
