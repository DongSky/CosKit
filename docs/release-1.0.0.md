# CosKit 1.0.0 — 第一个正式版本

定版日期：2026-10-10。作者：**凉月 / Suzutsuki**。

## 发布判断

本次以 **Windows x64 原生编辑器**为正式发布范围。完整库测试 3391 项通过、31 项按既有条件忽略；桌面应用 98 项通过。引擎、UI 和应用的全部 target 严格 Clippy 检查通过，发行构建成功。前序 P0/P1 已验证共享版本数据、后台事务、资源预算、原尺寸比较、模型事务与局部验收，本次版本升级没有引入新的原生算法修改。

因此将已完成验收的 beta.8 功能线定版为 1.0.0。正式版不表示所有平台都已验收，也不表示模型不会出错；保护、取消、失败不提交与版本回退仍是工作流的一部分。

## 相对 v0.1.x 的变化

- 延续 CosKit 独立开发的对话修图，整合 PhotoCraft 原生编辑器以补齐基础图像编辑。
- 从仅规划固定流程，发展为自主观察、工具发现、执行、复查与回退的 Harness；可由模型选择原生 MCP、生成式编辑或混合流程。
- 提供完整 stdio MCP、桌面桥接及精确笔刷控制。
- 新增 `.ckpipe` 工程，保留图层、参数、对话、审核记录与可回退版本；共享数据块，支持后台保存、恢复和参数重放。
- 新创作工作台采用 Fluent 基础规范、中性深色画布、可组合侧栏和缩略图版本条；支持同步原尺寸对比、放大与差异图。
- 完成 P0 资源与大图性能改进，以及 P1 AI 调用效率、细节验收和参数体验改进。

## 本次真实演示

使用作者指定的 1620×1080 花间人像，先移除元数据和私人文件名，再在正式版中执行自主调色、独立图层柔光笔刷、曲线参数查看、版本原尺寸比较和保存导出。重新打开 CKPipe 后，导出像素与保存前一致，画布仍为 1620×1080。

教程采用实际编辑器的原生窗口帧采集，避免系统录屏接口对 GPU 窗口返回旧帧；通过 MCP 驱动操作。剪辑标示等待加速和停留讲解，附中文合成旁白与中英字幕。演示素材、录屏与工程单独留在本地，不进入代码仓库或安装包。

## 交付与边界

Android 列入 TODO；macOS/Linux 本次未做平台运行验收。原生格式兼容性继承参考项目的已知边界；627/627 菜单覆盖不等于完全复刻 Photoshop 的所有行为。AI 仍受 40 MP 文档边界、预算、网络与供应商限制；审核采用有限裁片，生成式结果使用 sRGB 代理。安装器未商业签名。
