# CosKit 1.0.0-beta.3 · MCP 与 Cosplay 实图验证

日期：2026-10-09；平台：Windows x64，Rust 1.97.1。本文记录本轮实际执行范围，不将菜单覆盖率或单张照片测试视为 Photoshop 的全部行为一致性证明。上一轮完整集成记录见 [beta.2 验收](native-release.md)。

## 实现

- 参考公开的 [Photoshop MCP 接口](https://github.com/alisaitteke/photoshop-mcp)，保留原生 stdio MCP、无界面引擎及经过令牌认证的桌面桥接；增加 `brush_list`、`brush_stroke`、`ai_edit`、`ai_status`、`ai_configure`、`ai_cancel`、`ai_pending` 七个工具。原有 839 个引擎命令仍可发现、调用。[接入与参数文档](coskit-mcp.md)。
- 笔触使用文档像素坐标，支持笔刷预设、直径、不透明度、流量、随机种子、逐点压力、倾斜、旋转及时间；支持图层和蒙版。压力是否改变尺寸或透明度取决于预设动态设置，轨迹由点序列定义。
- AI 状态区分运行、应用成功、失败、取消、等待处理、打开为文档及丢弃；校验失败不会先修改设置；取消后不再应用已排队的完成事件。
- 下载并集成 David Revoy 的 [2023 Krita 笔刷包](https://www.davidrevoy.com/article953/krita-brushes-2023-01-bundle)：保留 19 个 CC0 采样笔尖及原文件、来源、许可证、SHA256 清单，另增加 9 个 CosKit 原创预设。动画 GIH 仅使用首帧，名称明确标注；不声称复刻 Krita 全部笔刷引擎或该包的全部预设。导入脚本为 `scripts/import-deevad-brushes.py`。

## 实际照片工作流

用户提供的照片为 **5472×3648**。原文件未改动，SHA256 为 `02122c0f971eb3c193b933791bd35d4d494167a55540954e85e82cf0daf1b690`。以下输出均保持此尺寸：

| 输出 | 图层 | 实际处理 |
|---|---:|---|
| `03-cosplay-clean` | 10 | 选区 AI 背景清理、三处手动仿制修复、蒙版肤色调整、分层光影、补发丝、冷色轮廓光 |
| `04-cosplay-effects` | 14 | 在干净版本上增加手绘能量弧光、CC0 笔尖氛围、稀疏星芒 |
| `05-ai-portrait-effects` | 11 | 在干净版本上测试规划器：肤色校正、轻度降噪、左侧背景光点三个步骤，合并调用图像模型 |

每个版本均保存 `.pcraft`、`.psd`、`.png`、`.jpg`。三个版本的 PCraft/PSD 已分别重开，尺寸与 10/14/11 个图层保留。所有照片、会话及测试产物位于被忽略的 `test_output/cosplay/` 和 `.dev-data/`，不进入发布包。

手绘工作通过实际 MCP 完成，记录了 **42 条精确笔触及 3 次仿制修复**，可查 `manual-strokes.json` 和 `manual-repairs.json`。没有使用外部图像编辑器替代 CosKit 绘制；Pillow 仅用于预览、比较、统计和第三方笔尖转换。

为了限制几十次滤镜测试的成本，另建 **1600×1067 的独立回归副本**。该副本明确执行了缩放，不能用来证明原始分辨率保留；成片的尺寸单独检查。图像模型中间结果的分辨率与文档尺寸是两个概念，本报告不声称模型输出具有原生 20MP 细节。

## 发现并修复的真实问题

原生选区快照输出的是不透明灰度覆盖图，而共享 AI 管线约定 alpha=255 为保护、alpha=0 为编辑。结果是带蒙版编辑返回全透明图层，界面却显示完成。修复为白色 RGB 加反向覆盖 alpha，并拒绝全透明结果。

增加了原生快照 → 共享提取/合成 → 原生图层应用的跨模块回归，覆盖 8/16/32 位。真实背景编辑重新执行后，保护的人脸、胸部及腿部采样像素逐值相同。组合工作流进一步检查 **16,294,484 个完全保护像素全部相同**，同时确认选区内确有修改，记录见 `ai-workflow-verification.json`。失败的早期结果保留为诊断记录，不计入成功案例。

## 限制与失败记录

- 规划模型早期返回 HTTP 503，错误被记录；之后恢复，三步规划与合并图像编辑成功。远端服务可用性不由应用保证。
- 组合测试虽开启审核，但独立 Review Agent 缺少 provider/model/key 配置，管线明确记录“审核跳过”。这次结果不计为自动审核通过，不能把图层应用成功等同于审核通过。
- 选区轮廓是手动定义的，发饰附近局部旧背景痕迹及边缘过渡仍可继续精修。实验 AI 特效版的局部体积光有选区边界感，因此保留为实验版本，推荐干净版或手绘特效版作为后续编辑基础。
- 保留 PhotoCraft 原有实现及其限制。此轮进行了广泛的照片工作流验证，但没有穷举所有命令参数、所有色彩配置或全部 PSD 特性；28 个预设通过也不意味着兼容任意 ABR/Krita 包。
- 发布包只包含程序、文档、启动脚本和许可证；不包含 `.env`、API 密钥、用户照片、控制令牌及私人会话。
