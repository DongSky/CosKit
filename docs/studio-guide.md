# CosKit Studio 使用指南

## 从本地修复到 AI 编辑

1. 导入照片，或点击「打开示例画布」。图像不会因导入而上传至模型。
2. 在图层面板选中需要修改的图层。需要保留独立绘画内容时，先新建空白图层；需要修复已有像素时，选择含图像内容的图层。
3. 使用左侧工具，设置画笔大小、硬度、强度。仿制图章和修复画笔先按 Alt 点击采样点，再绘制；污点修复直接涂过瑕疵。
4. 「编辑选区」提供画笔、矩形、多边形及羽化。确认后的选区同时限定本地调整和 AI 修改。内容感知填充需要局部选区，选区周围需有可用样本。
5. 输入对话指令并发送。模型以当前历史节点的合成图像为输入；裁剪/缩放后保持当前画布尺寸。参考图、智能规划、审核及供应商配置延续旧版。
6. 「导出图片」保存当前节点的合成图像。应用另会自动保存图层与全部分支到会话目录，重新启动可以继续编辑。

## 视图、历史与图层

滚轮缩放，H 切换平移，或按住空格临时平移；「适合画布」重置视图，点击缩放百分比显示 100%。按住「对比」查看父节点。

Ctrl/Cmd+Z 撤销；Ctrl/Cmd+Shift+Z 重做。撤销后继续编辑会生成新分支；旧子节点仍在会话中，原有分支导航可访问。对话记录中的历史图像可作为下一次编辑起点。每个笔画只产生一个历史节点。

所有基础操作作用于选中图层；裁剪、缩放、旋转和翻转作用于全部图层。有锁定图层时整图几何变换会给出错误，须先解锁。图层设置会生成新的快照，不修改旧节点图像。四种混合模式为正常、正片叠底、滤色、叠加。

亮度、对比度、饱和度与曝光的滑块在点击「应用调整」后提交，不会在拖动时改动原图。滤镜半径控制高斯模糊与锐化。裁剪工具拖动后先显示尺寸确认框，取消不会改动图像。

| 快捷键 | 工具 |
| --- | --- |
| H / 空格 | 平移 / 临时平移 |
| M | 打开选区编辑器 |
| C | 裁剪 |
| B / E | 画笔 / 橡皮 |
| J | 污点修复 |
| S / R | 仿制图章 / 修复画笔 |
| O / U / G | 减淡 / 加深 / 海绵去饱和 |
| I | 吸管（取色后切换画笔） |
| Esc | 放弃当前笔画或裁剪预览 |

## 配置与存储

开发启动：`npm run dev`。工作区 `.env` 中的密钥仅在 Rust 进程中读取，不打包到前端。应用内设置优先；要改用 `.env`，清空相应设置字段或使用独立开发目录。正式程序读取可执行文件同目录、其父目录、应用数据目录等位置的 `.env`。

开发数据位于 `.dev-data/`；正式 Windows 数据位于 `%APPDATA%/CosKit/`。`COSKIT_DATA_DIR` 可指定完整数据与设置目录。自动保存使用不可变 PNG 图层文件；不要在编辑期间手动删除这些文件。备份整个数据目录可保留全部历史，但其中的 `settings.json` 可能含个人 API 密钥，应私下保管。

## Beta 范围

本版是 RGBA8 工作流，导出合成 PNG（旧 JPEG 节点保持其格式）。不包含 PSD/PSB 文件互操作、CMYK/ICC 印刷软打样、16/32 位编辑、矢量/文字对象、智能对象或 PhotoCraft 的全部滤镜。单图最多 4000 万像素、最多 64 层，并对图层总像素和单次修复区域设置内存/计算限额；限额超出会报错而非悄悄降低分辨率。默认构建不启用可选 GPUPixel/PixelFree SDK，基础修复不依赖它们。
