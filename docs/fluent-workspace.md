# CosKit 创作工作台 · 1.0.0-beta.5

这一版采用 Fluent 2 的中性材质层级、克制强调色、4/8 px 间距节奏和圆角规范，仍使用现有 Rust / egui 原生编辑器。专业编辑命令、文件格式和图像引擎沿用 beta.4。

## 布局

- 顶部：项目与保存状态、命令搜索、工作空间、撤销 / 重做、保存与导出。菜单入口保留完整原生菜单；Ctrl+K 搜索全部命令。
- 左侧：完整工具组与同组工具展开；上方工具参数随当前工具变化。
- 中央：中性深灰画布，避免彩色底纹干扰颜色判断；状态栏区分显示缩放与文档真实像素尺寸。
- 右侧：单个可调宽度侧栏，切换 AI、调整、图层；“更多”包含颜色、历史、导航、文字、编辑参数。
- 组合面板：在“更多”中固定当前面板，侧栏下方显示第二个面板；可拖动分隔线，也可取消固定。
- 下方：CKPipe 缩略图版本条，支持命名记录、选择、并排对比、明确恢复。收起后从顶部“版本”或工作空间菜单重新展开。

“修图”默认显示调整与固定图层；“绘制”显示颜色与固定图层；“AI 创作”显示单个 AI 面板。工作空间与面板状态保存在本机偏好设置（遵从“记住工作区更改”）。完整面板布局可以从工作空间菜单启用，菜单 → 窗口 → CosKit Studio Workspace 可切回。

## AI 对话

输入框固定在侧栏底部，历史消息独立滚动。Ctrl+Enter 发送；点击示例只填入草稿。模型配置、参考图和高级流程选项位于“选项”。具体执行和审核记录默认折叠；已保存工程显示其自己的对话与工作流记录。

## 版本浏览

点击缩略图只选择版本，不修改画布，也不会执行历史命令。对比窗口并排显示所选版本和当前画面。“恢复所选版本”仍调用原有事务式恢复命令：先保护当前状态，再恢复旧版本，分支保留，可撤销。原尺寸图层和像素不经过缩略图重采样。

桌面版本预览在后台逐个生成，只处理可见或待对比的版本，缓存最多 24 张。预览最长边 768 px，并按文档 ICC 与当前显示器进行颜色转换；大工程首次解码需要时间，期间可以继续使用界面。项目切换清空旧版本选择及参数草稿，避免将另一项目的记录用于当前项目。损坏快照显示预览错误，不修改工程。

## 本版边界

这是新的原生工作台与设计规范的首版实现，不是 WinUI 控件迁移。beta.8 已加入可视化参数窗口，以及无需恢复版本的原尺寸同步对比、200% 放大和差异图；复杂参数仍提供高级 JSON 入口，详见 [P1 说明](p1-harness-and-review.md)。WASM 保留兼容编译，暂未提供桌面线程式预览加载。
