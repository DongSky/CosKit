# v1.0.0-beta.1 验收记录

日期：2026-10-09。验证平台：Windows x64，Rust 1.97.1，Node.js 24.11.1。

## 已交付

- Tauri 桌面工作台与所有原有 AI 编辑入口。
- 独立 PhotoCraft 修复算法 crate，源码及 MIT 许可证随仓库分发，不依赖相邻参考项目。
- 本地工具、选区修复、调色、几何变换和图层操作，共用不可变历史节点。
- 后台本地计算、输入限额、保存失败时不提交内存历史、旧会话兼容。
- 开发/正式数据隔离、`.env` 模型名兼容、真实 API 烟测和 CI 检查。

## 验证

自动化：`npm test` 共 **68 项通过、0 项失败**：30 项原有 Rust 单元测试、5 项图层回归、12 项本地编辑与透明度回归、15 项 PhotoCraft 算法测试、6 项前端状态测试。另有 6 项明确标记 ignored 的外部资源/网络测试跳过，默认未启用外部 GPU SDK 测试。`npm run check` 与 `git diff --check` 通过。

真实模型：`gpt-6.1-sol` 文本请求通过；`gpt-image-2` 图像编辑请求通过，返回 816×816 可解码图像，人工查看确认将红方块改成蓝方块。首次图像请求遇到 HTTP 429，稍后有限重试成功。烟测只发送程序生成的几何图，不发送个人照片。

桌面检查：使用 computer-use 在真实 WebView2 窗口导入 PNG、打开示例、绘制笔画、查看图层与本地历史，重启后会话恢复。Ctrl+Z 恢复原始图像，Ctrl+Shift+Z 恢复同一笔画节点；拖动裁剪、确认后得到 827×637 图像。验证深色与浅色主题。原生保存对话框导出 1200×800 RGBA PNG，导出文件与对应节点的 PNG 字节完全一致。

构建：Windows release 与 NSIS 安装包构建成功。最终安装包由最新源码重新构建，未签名；未实际安装到系统。macOS / Linux / 移动端未在本机执行验证。

产物：`dist/CosKit_1.0.0-beta.1_x64-setup.exe`（安装包）、`dist/CosKit_1.0.0-beta.1_x64_portable.zip`（程序、许可及指南）。生产包不包含 `.env`、个人设置或测试会话。生产版读取原有 CosKit 系统数据，工作区调试推荐 `npm run dev`。

## 已知边界

本版不等于完整 Photoshop/PhotoCraft 功能移植；明确交付范围见开发方案和使用指南。大图修复质量依赖纹理与选区，内容感知填充不能保证复杂人物结构还原。对话模型质量和限流由供应商控制。默认构建的 CPU 修复已验证，可选 GPU 美颜后端未重新编译验证。旧库与二进制同名引发 Windows PDB 文件名警告，当前构建成功，不影响应用运行。
