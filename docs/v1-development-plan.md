# CosKit v1.0.0-beta.1 开发方案

## 参考项目审计

CosKit 0.1.5：Tauri 2 + 原生 JavaScript/CSS；Rust `commands` 是 IPC 边界，`engine` 管会话树、不可变图层文件和工作流，`planner/skills/reviewer/workflow` 管多步 AI 修图，`gemini_client/openai_client` 管供应商。已有画布、对话侧栏、蒙版编辑器、历史分支、参考图、图层混合、GPU 美颜和导出。主要不足：基础工具缺失，图层藏在全屏查看器，传统编辑与 AI 没有统一操作入口。现有图层属性操作原地修改节点，保存错误被忽略，开发目录 .env 和 OPENAI_LLM_MODEL 未被读取。

PhotoCraft：纯 Rust egui/eframe/wgpu 桌面应用；基础几何/色彩/瓦片 → 文档 → 操作/画笔/算法 → 合成 → 文件格式 → engine 命令 → UI。其 UI 遵循顶部菜单/工具属性、左工具栏、中画布、右属性与图层的布局。修复算法包含 PatchMatch 内容感知填充、Poisson 融合、减淡/加深/海绵。图层、撤销、命令与渲染分离可借鉴。它并非完整 Photoshop 的替代品，其路线图亦列明尚未实现部分；不能将参考项目宣传的功能全部当成本版本交付。

## 架构决定

保留 CosKit 桌面平台和 AI 工作流。将 PhotoCraft 独立的 `inpaint/poisson/retouch` 模块连同原始 MIT 许可移入独立 vendor crate，保留其测试与来源记录；不嵌套另一个窗口，不引入 egui/wgpu UI，不依赖参考目录的绝对路径。新增 Rust 本地编辑服务与统一命令；前端工作台只负责交互、预览和提交。算法在后台线程运行。

每次本地操作产生新的会话子节点，旧节点像素不变。图层操作同样以快照提交；撤销/重做选择父/子节点，分支继续保留。几何变换作用于全部图层并记录节点尺寸；AI 使用当前节点尺寸，避免裁剪后被拉回原图大小。旧版会话无须破坏性迁移。

## v1 范围与步骤

1. 基础设施：独立算法 crate、版本号、开发启动与 .env 兼容、许可证说明。
2. 本地编辑：画笔、橡皮、仿制图章、修复画笔/污点修复、内容感知填充、减淡/加深；亮度/对比度/饱和度/曝光、模糊/锐化、旋转/翻转、裁剪/缩放。输入限额和选区外像素保护。
3. 工作台：工具栏、参数、可缩放平移画布、共享选区、常驻图层、撤销重做、导出。保留对话规划、参考图、分支和供应商设置。
4. 图层：创建/复制/删除/排序、可见性/锁定/混合/不透明度；编辑目标明确，操作可撤销。会话自动持久化。
5. 验证：Rust 算法/编辑/历史回归测试、前端静态与交互检查、真实模型小图烟测、Windows 编译和打包；记录实际结果。

## 发布约束

使用 v1.0.0-beta.1：核心工作流完成后交付可运行版本，beta 表示尚未完成跨平台/真实摄影大图的广泛验证。本版像素编辑沿用 CosKit 的 RGBA8 管线，不声称支持 PhotoCraft 的完整 PSD/CMYK/16/32 位色彩、矢量排版和全部 Photoshop 滤镜。高级色彩和 PSD 可在后续引入完整文档引擎。不得用静态样例冒充可用编辑或模型验证。
